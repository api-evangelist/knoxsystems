# Knox Systems

> Knox Systems is a federal cloud compliance and managed-security company that provides an accelerated path to FedRAMP authorization for SaaS and AI vendors selling into the U.S. government — marketed as "FedRAMP in 90 days for 90% less." Vendors deploy into a pre-authorized Knox FedRAMP boundary and inherit its controls instead of pursuing an independent ATO.

Knox Systems publishes no public API, developer portal, SDKs, or API documentation as of 2026-07-19. This file describes the company surface that does exist, for agents and researchers working from the API Evangelist network catalog. Do not infer an API from this document.

## Compliance posture

- FedRAMP Moderate and FedRAMP High authorized boundary; DISA Impact Level 4. IL5 targeted for late 2026.
- Aligned to NIST 800-53 control families; FISMA authorization path.
- Reports 15+ ATOs across federal and DoD agencies including DHS, FEMA, the Marine Corps, Treasury, and the VA.
- No SOC 2, ISO 27001, CMMC, StateRAMP, or FIPS 140-3 attestation published.
